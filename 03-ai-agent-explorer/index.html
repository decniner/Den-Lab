Keep these ideas

A useful mental model for agent systems.

Model

Interprets context and selects the next action.

Tools

Let the system fetch information or affect the outside world.

Observation

The result of a tool call becomes new context.

Loop

Repeat until the task is complete or the system should stop.

Everything here is illustrative. No network requests are made.
