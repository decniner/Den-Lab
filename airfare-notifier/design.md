# Airfare notifier

User-authorized scope, updated 2026-10-03: free services only; NRT–MNL–NRT; one adult economy; both legs nonstop; departure six to twelve calendar months ahead; stay nine to twenty nights; threshold JPY 25,000. The latest user instruction accepts the source-displayed round-trip total without independent additional-cost verification. Default to qualifying alerts only; configurable daily-summary mode preserves above-budget/no-result summaries.

Use the live, public, account-free OctoTrip MCP search endpoint, tested on this route and observed to return Cebu Pacific. Never label its quotes supplier-checkout verified. Source coverage is a subset, not exhaustive; use a bounded daily rotating date sample, with exactly checked dates recorded. Repeat the winning date search before sending and select the cheapest qualifying complete nonstop result in that refreshed response. Missing mandatory fields, currency mismatches, incomplete round trips and connecting flights are rejected. Unknown or suspicious baggage is explicitly described as unverified.

Reuse shopping-notifier's Telegram sender, safe transport-failure handling, GitHub API client and local run lock, with existing TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID secrets. Existing notifier files remain untouched. The new state schema and dedicated airfare-notifier-state branch are isolated. Persist a daily delivery claim before sending: an ambiguous send or process crash blocks automatic retry that day, preventing duplicate alerts at the cost of possible missed delivery. Provide documented manual recovery. All state failures stop delivery. Operations are keyed by stable failure category and day; later qualifying fare alerts remain possible after an earlier error.

Schedule separately in GitHub Actions at 22:00 UTC (07:00 JST next day), with concurrency serialization, bounded duration, secrets, and persistent state. Exact time is not guaranteed; workflows can be delayed or dropped. Local --dry-run performs live searches but never sends, writes notification history, or uses remote state. JSON configuration controls calendar-month window, night range, threshold, sample count, request timeout, attempts, and alert mode. No paid signup, CAPTCHA bypass, reservation, or ticket purchase.
