Use this structure:

style.css

- Design tokens and CSS custom properties
- Typography
- Colours
- Layout
- Responsive behaviour
- Component styling
- Focus states
- Animations
- Reduced-motion rules
- Print styling where useful

app.js

Contains all application behaviour:

- Navigation enhancements
- Scroll progress
- Interactive capability controls
- Lifecycle interactions
- Expandable evidence
- Score animations
- Scroll reveals
- Other useful interface behaviour

Use a normal deferred script. Do not use JavaScript modules, imports, or features that require serving the files over HTTP.

Separation rules

- Do not embed application CSS inside "<style>" tags.
- Do not use inline "style" attributes.
- Do not embed application JavaScript inside the HTML.
- Do not use inline event handlers such as "onclick".
- Attach event listeners from "app.js".
- Inline SVG markup is allowed inside "index.html".
- Keep substantive profile content in the HTML so it remains readable if JavaScript fails or is disabled.

All three files must be complete and work together without modification.
