# Book summary production agent rules

1. Read `SKILL.md`, `STYLE_LOCK.md`, `CAPTION_SPEC.md`, `PRODUCTION_SPEC.md`, and both manifests before work. Required exact references are `Dracula_Hook_Cover.png`, `Dracula_YouTube_Short_Painterly.mp4`, and `A Room of One’s Own Legacy.png`. Keep reference media local and verify hashes; never commit reference media or machine-specific paths.
2. Use A Room of One’s Own Legacy for hook-cover composition, title-at-top typography, author line, palette, and premium illustrated quality. Keep Dracula cover as a secondary series reference; use Dracula video frames for animation, scene framing and captions. Never copy geometric placeholder artwork as acceptable final art. If any exact reference is unavailable or mismatched, stop and report the missing file/hash.
3. Before animation, make original high-resolution raster illustrations and build the contact sheet with `scripts/build_contact_sheet.py` from the actual cover/scene assets. Use a consistent expressive stickman-inspired storybook character identity, premium hand-painted rendering, and a coherent 2–3 tone warm ivory/charcoal/deep burgundy palette. Reject primitive SVG people, line limbs, circles, geometric placeholders, flat icon art, wireframes, and unrelated character redesigns. Record a human quality-gate approval in the project manifest; the automated script cannot judge aesthetics.
4. A hook cover is 1080×1920 PNG. Animate it with Remotion. It occupies frames inside the original runtime, replacing/transitioning from the original opening scene. Never append time or alter Kokoro narration/cue timing to make room.
5. Preserve the local Kokoro narration. Use shared `components/Caption.tsx`; all words share a single baseline, font, size and line box. Only highlight fill/opacity changes. Validate cues and inspect ascenders/descenders in rendered frames; fix any baseline drift.
6. Use project-relative paths and Python `pathlib`. Commands are argv arrays executed with `shell=False`. Provide both `scripts/run_production.sh` (macOS) and `scripts/run_production.ps1` (Windows PowerShell). Keep dependency versions/model identifiers in the project record.
7. Run `scripts/validate_manifest.py`, `scripts/validate_captions.py`, and `scripts/production.py`. The production gate fails closed for missing references, image-generation tool, artwork/contact sheet, narration, or rendering inputs. Review contact sheet before render. Verify MP4 decode, 1080×1920/30fps, audio stream, duration, spoken narration and caption synchronization. Metadata checks alone do not prove narration or visual quality.
8. Compare contact sheet and representative final frames with the inspected exact references, inspect transition and caption baselines, and report measured results and any unverified claims. Do not report PASS without looking at rendered imagery and playback.
