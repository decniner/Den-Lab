# Book summary production agent rules

1. Read `SKILL.md`, `STYLE_LOCK.md`, `CAPTION_SPEC.md`, `PRODUCTION_SPEC.md`, and both manifests before work. Required exact references are `Dracula_Hook_Cover.png`, `Dracula_YouTube_Short_Painterly.mp4`, and `A Room of One’s Own Legacy.png`. Keep reference media local and verify hashes; never commit reference media or machine-specific paths.
2. Use A Room of One’s Own Legacy for hook-cover composition, title-at-top typography, author line, palette, and premium illustrated quality. Keep Dracula cover as a secondary series reference; use Dracula video frames for scene pacing, framing and captions. Never copy geometric placeholder artwork as acceptable final art. If any exact reference is unavailable or mismatched, stop and report the missing file/hash.
3. Before video assembly, make original high-resolution raster illustrations and build the contact sheet with `scripts/build_contact_sheet.py` from the actual cover/scene assets. Use a consistent expressive stickman-inspired storybook character identity, premium hand-painted rendering, and a coherent 2–3 tone warm ivory/charcoal/deep burgundy palette. Reject primitive SVG people, line limbs, circles, geometric placeholders, flat icon art, wireframes, and unrelated character redesigns. Record a human quality-gate approval in the project manifest; the automated script cannot judge aesthetics.
4. Generate one premium still illustration per narration scene, each mapped to contiguous narration timing. The hook cover is a 1080×1920 PNG and occupies frames inside the approved runtime, replacing the opening visual. Use `components/StillImageSequence.tsx` with the existing Remotion renderer for still-image sequencing, cuts, crossfades, or subtle whole-image camera movement. Do not animate characters, add skeletal rigs, or reconstruct scenes with vectors. Never append time or alter Kokoro narration/cue timing to make room.
5. Preserve the local Kokoro narration. Use shared `components/Caption.tsx` and the measured approximate treatment in `CAPTION_SPEC.md`; FFmpeg and Remotion must share type weight/size, baseline, spacing, outline, shadow, colors, and active-word fill. All words in a cue remain fixed on one baseline and phrase; the current word changes to burgundy at supplied word times. Do not add a caption backing plate or capsule. Do not move or scale the glyphs. Validate cues and inspect ascenders/descenders in decoded frames; fix any baseline drift.
6. Use project-relative paths and Python `pathlib`. Commands are argv arrays executed with `shell=False`. Provide both `scripts/run_production.sh` (macOS) and `scripts/run_production.ps1` (Windows PowerShell). Keep dependency versions/model identifiers in the project record.
7. Run `scripts/validate_manifest.py`, `scripts/validate_captions.py`, and `scripts/production.py`. The production gate fails closed for missing references, artwork/contact sheet, narration, or rendering inputs. Require the image-generation executable while new artwork generation is pending; pre-generated, reviewed artwork does not need a generator during rendering. Review contact sheet before render. Verify MP4 decode, 1080×1920/30fps, audio stream, duration, spoken Kokoro narration and word-synchronized captions. Metadata checks alone do not prove narration or visual quality.
8. Compare contact sheet and representative final frames with the inspected exact references, inspect transition and caption baselines, and report measured results and any unverified claims. Do not report PASS without looking at rendered imagery and playback.
9. Require a human-approved emotional-context record per scene (narration meaning, intended tone, expression, body language, environment). Hardship scenes cannot use cheerful expressions unless the story explicitly warrants it and a reviewer records why. Preserve compositions when correcting expressions where feasible.
10. Before using either gold-standard package, verify `baseline/SHA256SUMS.json`. Never overwrite `baseline/mans-search-for-meaning/approved/` or `baseline/meditations/approved/`; write new renders to a separate per-book output directory.
11. Every new narration and caption track must start with `[Book Title] by [Author]. A book summary in under 3 minutes.` followed immediately by the summary. Run `scripts/validate_opening.py` and keep the final runtime strictly below 180 seconds. Preserve the historical approved *Meditations* colon literally. Pin the explicitly approved Kokoro voice/settings in project manifests rather than inferring a machine default.
